# 💜 D4Donation

> Give what you can. Help where it matters.

D4Donation is a web-based charity and donation platform designed to connect donors, people seeking help, and charitable organizations through a simple and organized donation process.

The platform allows users to discover charities, explore their causes, donate items, request assistance, and follow the donation workflow.

## 🔄 How D4Donation Works

    ┌──────────────────────────┐
    │  1. Pick a Charity       │
    │                          │
    │  Browse charitable       │
    │  organizations           │
    └────────────┬─────────────┘
                 │
                 ▼
    ┌──────────────────────────┐
    │  2. Donate or Request    │
    │                          │
    │  Offer something to give │
    │  or request needed help  │
    └────────────┬─────────────┘
                 │
                 ▼
    ┌──────────────────────────┐
    │  3. Charity Confirms     │
    │                          │
    │  Charity reviews the     │
    │  request and responds    │
    └────────────┬─────────────┘
                 │
                 ▼
    ┌──────────────────────────┐
    │  4. Done                 │
    │                          │
    │  Donation is collected   │
    │  or help is delivered    │
    └──────────────────────────┘

### 1️⃣ Pick a Charity

Users can browse charities according to different causes such as:

- Food
- Education
- Health
- Clothing
- Emergency Relief

### 2️⃣ Donate or Request

Users can either:

- Offer something they want to donate
- Request assistance from a charity

### 3️⃣ Charity Confirms

The charity reviews the submitted request and can accept or decline it.

### 4️⃣ Done

After the donation is collected or the requested assistance is delivered, the request can be marked as completed.
